## 💡 Alur Cepat Kerja:
1. Ambil screenshot dalam format `.png` biasa.
2. Salin ke folder proyek terkait di `public/projects/<slug>/`.
3. Cukup chat: *"tolong proses screenshot [nama-proyek]"*.
4. Saya akan otomatis mengonversi ke `.webp` ringan (< 80 KB), mendaftarkannya ke YAML, dan men-deploy ke live website!
